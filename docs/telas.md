# Modelagem das Telas - FinanceWeb

## 1. Landing Page

Objetivo:
Apresentar o sistema FinanceWeb.

Componentes:
- Logo
- Apresentação do sistema
- Botão Login
- Botão Cadastro

---

## 2. Login

Objetivo:
Permitir autenticação do usuário.

Campos:
- E-mail
- Senha

Botões:
- Entrar
- Recuperar Senha

---

## 3. Cadastro

Objetivo:
Criar uma conta de usuário.

Campos:
- Nome Completo
- E-mail
- Senha
- Confirmar Senha

Botão:
- Criar Conta

---

## 4. Dashboard

Objetivo:
Apresentar resumo financeiro.

Componentes:
- Saldo Atual
- Receitas Totais
- Despesas Totais
- Economia do Mês
- Gráfico Financeiro

---

## 5. Receitas

Objetivo:
Gerenciar receitas.

Funcionalidades:
- Adicionar
- Editar
- Excluir
- Listar

---

## 6. Despesas

Objetivo:
Gerenciar despesas.

Funcionalidades:
- Adicionar
- Editar
- Excluir
- Listar

---

## 7. Metas Financeiras

Objetivo:
Controlar objetivos financeiros.

Funcionalidades:
- Criar Meta
- Atualizar Progresso
- Visualizar Percentual Concluído

---

## 8. Relatórios

Objetivo:
Visualizar indicadores financeiros.

Componentes:
- Relatório Mensal
- Relatório Anual
- Exportação PDF

---

## 9. Administração de Usuários

Objetivo:
Gerenciar usuários do sistema.

Funcionalidades:
- Visualizar usuários
- Ativar conta
- Desativar conta
