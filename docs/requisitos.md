# Levantamento de Requisitos - FinanceWeb

## Requisitos Funcionais

- RF01: Cadastro de usuário
- RF02: Login
- RF03: Recuperação de senha
- RF04: Cadastro de receitas
- RF05: Cadastro de despesas
- RF06: Visualização de saldo
- RF07: Dashboard financeiro
- RF08: Metas financeiras
- RF09: Relatórios financeiros
- RF10: Consulta de cotação monetária via API

## Requisitos Não Funcionais

- RNF01: Interface responsiva
- RNF02: Acessibilidade
- RNF03: Segurança dos dados
- RNF04: Hospedagem em nuvem
- RNF05: Controle de versão com GitHub
- RNF06: Banco de dados PostgreSQL
